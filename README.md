# Kalinga Stone — Homepage v2

Standalone React/Vite implementation of the Kalinga Stone Figma homepage, with a three-state opposing-parallax hero.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The app is self-contained inside this folder, including its package manifest, lockfile, fonts, images, Vercel configuration, and build output.
